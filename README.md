# dsh-env-switcher

> DeepSeek Harness 环境变量管理插件

## 功能

- 🔧 **环境管理**: 解析、写入、验证 .env 文件
- 🔄 **环境切换**: 快速切换 .env.development/.env.production
- 📊 **差异对比**: 比较两个 .env 文件的差异
- 💾 **备份恢复**: 备份和恢复环境配置

## 工具

| 工具名 | 说明 |
|--------|------|
| `env_list` | 列出环境变量 |
| `env_get` | 获取变量值 |
| `env_set` | 设置变量 |
| `env_diff` | 对比两个 .env |
| `env_switch` | 切换环境配置 |
| `env_backup` | 备份 .env |
| `env_validate` | 验证变量 |
